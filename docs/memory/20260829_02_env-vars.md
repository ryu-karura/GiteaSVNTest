# 20260829_02 環境変数標準定義

## 成果

`docs/env-vars.md` 作成。

## 内容

- 命名規則: `<サービス>_<用途>`、大文字 `_` 区切り。
- サービス: `GITEA` / `GITHUB` / `REDMINE` / `SVN` / `GIT`
- トークン接尾辞: Gitea/GitHub = `API_TOKEN`、Redmine = `API_KEY`
- 主要変数:
  - Gitea: `GITEA_BASE_URL` `GITEA_API_TOKEN` `GITEA_OWNER` `GITEA_REPO`
  - GitHub: `GITHUB_API_URL` `GITHUB_TOKEN` `GITHUB_OWNER` `GITHUB_REPO`
  - Redmine: `REDMINE_BASE_URL` `REDMINE_API_KEY` `REDMINE_PROJECT`
  - SVN: `SVN_BASE_URL` `SVN_USERNAME` `SVN_PASSWORD`
  - Git: `GIT_USERNAME` `GIT_PASSWORD` `GIT_AUTHOR_NAME` `GIT_AUTHOR_EMAIL`
- AI が最初に実行する未設定チェック用 bash スニペット同梱。
