# 20260829_11 RTK 利用の確認と指示ファイル見直し

## 調査結果：現状 RTK は使われているか

- Claude Code の PreToolUse フック（`~/.claude/settings.json` の `rtk hook claude`）が
  `git` / `curl` を自動で `rtk git ...` / `rtk curl ...` に書き換えている（透過的、0 トークンオーバーヘッド）。
  → **git / curl は既に RTK 経由で実行されている**。
- `svn` はフック対象外。前置されないので素の `svn` が走る（`rtk svn` は golden rule で安全だが未適用）。
- `.rtk/filters.toml` はテンプレート（コメントのみ）。`[rtk] untrusted ... Filters NOT applied` の
  警告はこの空ファイルが未 `rtk trust` なだけで、組み込みフィルタ（git/curl 等）は動作している。
- 実測: `rtk curl` に書き換えられても JSON レスポンスはそのまま渡され、`jq -r '.number'` 等の
  パースは壊れない（`command curl` と同一出力）。PR 作成・チケット作成の結果取得も問題なし。

## 指示ファイルの見直し（RTK を使うルールを明記）

- `ai-instructions/common.md` に「## RTK（利用可能なら使う）」節を追加:
  - `rtk` があれば `git` / `svn` / `curl` に前置
  - Claude Code はフックが `git` / `curl` を自動 RTK 化。`svn` は明示的に `rtk svn`
  - JSON を `jq` パースする `curl` も `rtk curl` で可。生応答が要るなら `rtk proxy curl ...`
  - `rtk` が無い環境（CI / 一部 Copilot）ではそのまま。レシピ本文は `rtk` 無しで記載（可搬性）
- 各レシピ冒頭に 1 行の参照を追加: `git-svn-ops.md` / `gitea-pr.md` / `github-pr.md` /
  `redmine-issue.md`
- `docs/healthcheck.md` 冒頭にも注記
- `CLAUDE.md`（プロジェクト節）/ `.claude/rules/ai-execution.md` /
  `.github/copilot-instructions.md` / `.github/instructions/ai-execution.instructions.md` に
  RTK 前置ルールを 1〜数行で追記

## 方針

レシピのコマンドは生（`rtk` 無し）のまま維持し、「`rtk` があれば前置」をルールとして
1 箇所（common.md）に集約 + 各所から参照。理由: Copilot / CI など `rtk` 非搭載環境で
`rtk: command not found` にならないようにするため。
